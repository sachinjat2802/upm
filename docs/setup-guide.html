📦 Install CPM

Build CPM from source and add it to your PATH.

1

Install Rust (if not already installed)

Visit rustup.rs or run:

Windows
macOS / Linux
# Download and run rustup-init.exe from https://rustup.rs
# Or via winget:
winget install Rustlang.Rustup

# Restart your terminal, then verify:
rustc --version
# → rustc 1.XX.0PowerShell
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh

# Restart your terminal, then verify:
rustc --versionBash
2

Clone and Build CPM

git clone https://github.com/upm-org/upm.git
cd upm
cargo build --release

# Binaries are at:
#   target/release/cpm.exe   (or cpm on macOS/Linux)
#   target/release/upm.exe   (or upm on macOS/Linux)
3

Add to PATH

Windows
macOS / Linux
# PowerShell (run as Administrator)
Copy-Item target\release\cpm.exe C:\Windows\System32\
Copy-Item target\release\upm.exe C:\Windows\System32\

# Or add the target/release folder to your PATH environment variablePowerShell
# Copy to a directory on your PATH
cp target/release/cpm ~/.local/bin/
cp target/release/upm ~/.local/bin/

# Or add to ~/.bashrc or ~/.zshrc:
export PATH="$PATH:$(pwd)/target/release"Bash
4

Verify Installation

cpm --version
# → upm 0.1.0

cpm --help
# → Shows full command reference with emoji icons

🔗 Add Languages at Any Time

One of CPM's most powerful features: you're never locked in. Add new language ecosystems to an existing project whenever you need them.

♾️

No Lock-In. Add Ecosystems Anytime.

Started with Python? Add Node.js tomorrow. Need Rust next month? Just cpm add cargo:serde. CPM handles it all.

How It Works

1

You start with a Python-only project

cpm init -l python -y
cpm add pip:requests
cpm add pip:pandas

At this point, your project has: upm.toml, pyproject.toml, main.py

2

Weeks later, you need Node.js for image processing

Just add a Node.js package — CPM automatically bootstraps the ecosystem:

# This works at ANY time — no re-init needed!
cpm add npm:sharp
cpm add npm:puppeteer

# CPM will:
# 1. Detect that npm/pnpm ecosystem is now needed
# 2. Create package.json if it doesn't exist
# 3. Run pnpm install (or npm install)
# 4. Update upm.toml with the new foreign dependency
3

Months later, you need Rust for performance

cpm add cargo:serde
cpm add cargo:tokio

# Same thing — CPM detects cargo ecosystem
# and manages it alongside Python and Node.js
4

Check your full polyglot status

cpm status

# ╭──────────────────────────────────────────────────────╮
# │  📊 Project Status                                  │
# ╰──────────────────────────────────────────────────────╯
#
#   Name     my-app
#   Version  0.1.0
#   Language python
#
#   Detected Ecosystems:
#     ✔ 🐍 uv (Python) (pyproject.toml)
#     ✔ 📦 pnpm (Node.js) (package.json)
#     ✔ 🦀 cargo (Rust) (Cargo.toml)
🔮 Key insight: Every cpm add, cpm install, cpm update, cpm audit, and cpm outdated automatically scans for all active ecosystems. You never need to "re-register" or "re-init" — just add packages and CPM handles the rest.

✅ Verify Your Setup

Run these commands to confirm everything is working.

  • ✔ cpm --version — Shows version number
  • ✔ cpm --help — Shows full command reference with emoji icons
  • ✔ cpm detect — Runs the scoring engine (even if no ecosystems found)
  • ✔ cpm bridge status — Shows transport tiers

Test Bridge Communication

# If you have Python installed:
cpm bridge call python:math.sqrt '[144.0]'
# → 12.0

# If you have Node.js installed:
cpm bridge call node:echo '["hello from CPM!"]'
# → "hello from CPM!"

🚀 Your First Project

Ready? Create your first polyglot project in under 30 seconds.

# Create a Python project with Node.js support
mkdir my-first-app && cd my-first-app
cpm init -l python -f node -y

# Add some packages
cpm add pip:requests
cpm add npm:express

# Install everything at once
cpm install

# See your project status
cpm status

# Try a cross-language bridge call
cpm bridge call python:math.sqrt '[9]'
🎉 That's it! You now have a polyglot project managed by one tool. Read the full Getting Started Guide for language-specific examples and real-world recipes.

🔍 Troubleshooting

❌ "command not found: cpm"

Make sure the binary is on your PATH. Run where cpm (Windows) or which cpm (macOS/Linux) to check.

❌ "Failed to spawn python host"

Python is not installed or not on PATH. Install Python and verify with python --version.

❌ "Unknown ecosystem adapter: 'xyz'"

Check the supported ecosystem names — use npm, pip, cargo, etc.

❌ Build fails with "linker not found" on Windows

Install Visual C++ Build Tools or run winget install Microsoft.VisualStudio.2022.BuildTools.

❌ "pnpm: command not found" after cpm install

Install pnpm globally: npm install -g pnpm. CPM delegates to native package managers — they must be installed.

Getting Started with
CPM / UPM

Learn how to set up projects in any language, add dependencies from other ecosystems, and call foreign functions — all from one CLI.

⚡ Installation

Build CPM from source and add it to your PATH.

# Clone and build
git clone https://github.com/upm-org/upm.git
cd upm
cargo build --release

# The binaries are at:
#   target/release/cpm.exe
#   target/release/upm.exe

# Verify
cpm --version
# → upm 0.1.0
💡 Both cpm and upm are identical binaries — use whichever name you prefer.

🚀 Your First Project

Create a polyglot project in seconds with interactive prompts or flags.

Interactive Mode

mkdir my-app && cd my-app
cpm init

CPM guides you through three questions — project name, base language, and foreign ecosystems:

  ╭──────────────────────────────────────────────────────╮
  │  🚀 UPM Project Initializer                         │
  ╰──────────────────────────────────────────────────────╯

  ? Project name [my-app]: my-app
  ? What is your base language?
   › 1) 📦 JavaScript / TypeScript
     2) 🐍 Python
     3) 🦀 Rust
     4) 🐹 Go
  › Choose [1]: 2

  ? Which foreign ecosystems do you want to support?
     1) 📦 JavaScript / TypeScript
     2) 🦀 Rust
     3) 🐹 Go
  › Choose: 1,3

Non-Interactive One-Liners

# Python + Node.js support
cpm init -l python -f node -y

# Rust + Python + Go
cpm init -l rust -f python,go -y

# JavaScript + everything
cpm init -l javascript -f python,rust,go -y

What Gets Created

my-app/
├── upm.toml              # CPM manifest (tracks all ecosystems)
├── pyproject.toml         # Python manifest (base language)
├── main.py               # Python entry point
├── package.json           # Node.js manifest (foreign)
├── index.js               # Node.js entry point
├── go.mod                 # Go manifest (foreign)
└── main.go                # Go entry point

Example src/main.rs

use serde::Deserialize;

#[derive(Deserialize, Debug)]
struct Repo {
    name: String,
    stargazers_count: u64,
}

#[tokio::main]
async fn main() -> Result<(), Box<dyn std::error::Error>> {
    let repo: Repo = reqwest::get("https://api.github.com/repos/rust-lang/rust")
        .await?.json().await?;
    println!("{} has {} stars!", repo.name, repo.stargazers_count);
    Ok(())
}Rust

🔗 Importing Foreign Packages

The core superpower of CPM: use packages from any ecosystem in the same project.

1

Add the foreign ecosystem at init time

# Base is Python, but you also need Node.js packages
cpm init -l python -f node -y
2

Add dependencies from any ecosystem

# Python packages (your base language)
cpm add pip:requests
cpm add pip:pandas

# Node.js packages (foreign ecosystem)
cpm add npm:sharp           # Image processing
cpm add npm:puppeteer       # Browser automation
3

Install everything at once

cpm install
# → Runs BOTH uv sync (Python) AND pnpm install (Node.js)
4

Call foreign code via the bridge

# From your Python project, call Node.js sharp to resize an image
cpm bridge call node:sharp.resize '["photo.jpg", 800, 600]'
ℹ️ All foreign dependencies are tracked in upm.toml under [foreign_dependencies] using the format "ecosystem:package" = "version".

🌉 Cross-Language Bridge (RPC)

Call functions in foreign languages over stdio RPC — no setup, no servers, no boilerplate.

How It Works

Your CLI / Rust Host ──── stdio ────▶ Python / Node.js Host
upm-bridge/1 · 4-byte BE length-prefixed JSON frames

Python Bridge Examples

# Math operations
cpm bridge call python:math.sqrt '[144.0]'
# → 12.0

# Hash data
cpm bridge call python:hash.sha256 '["hello world"]'
# → "b94d27b9934d3e08..."

# Parse a document
cpm bridge call python:docling.parse '["report.pdf"]'
# → { "filename": "report.pdf", "pages": 28, "sections": [...] }

Node.js Bridge Examples

# Image processing
cpm bridge call node:sharp.resize '["photo.jpg", 800, 600]'
# → { "resized": true, "width": 800, "height": 600 }

# Crypto hashing
cpm bridge call node:crypto.sha256 '["hello world"]'

Add Your Own Methods

Extend the host scripts in the hosts/ directory:

# In hosts/python_host.py, inside handle_request():

elif method == "my_custom.analyze":
    text = args[0]
    word_count = len(text.split())
    result = {
        "text_length": len(text),
        "word_count": word_count,
        "avg_word_length": len(text) / max(word_count, 1)
    }
    send_message({"type": "response", "id": req_id, "result": result, "error": None})Python
# Then call it:
cpm bridge call python:my_custom.analyze '["Hello world from CPM"]'
# → { "text_length": 20, "word_count": 4, "avg_word_length": 5.0 }

📄 Understanding upm.toml

The single source of truth for your polyglot project.

# Project metadata
[project]
name = "my-polyglot-app"
version = "0.1.0"
primary_language = "python"

# Active ecosystem adapters
ecosystems = ["uv", "pnpm", "cargo"]

# Cross-ecosystem dependency tracking
[foreign_dependencies]
"pip:requests" = "^2.31"
"pip:pandas" = "^2.2"
"npm:express" = "^4.19"
"cargo:serde" = "^1.0"

# Bridge transport configuration
[transports]
default_tier = "rpc"  # Options: "rpc", "embed", "ffi"TOML

⌨️ Command Reference

Every command, alias, and flag at a glance.

# ── Project Lifecycle ──────────────────────────────
cpm init                        # Interactive setup
cpm init -l python -f node -y   # Non-interactive
cpm status                      # Project overview
cpm detect                      # Show detected ecosystems

# ── Dependency Management ──────────────────────────
cpm install                     # Install all (alias: is)
cpm install --parallel          # Install ecosystems concurrently (-p)
cpm install --filter python     # Target specific language (-f)
cpm add requests                # Smart auto-detects ecosystem prefix!
cpm add pip:requests            # Add explicit dep (alias: a)
cpm remove pip:requests         # Remove dep (alias: rm)
cpm update --parallel           # Update all concurrently
cpm outdated --filter node      # Show outdated node deps
cpm audit                       # Security vulnerabilities

# ── Running Code ───────────────────────────────────
cpm run dev                     # Run script across ecosystems
cpm run build
cpm run test

# ── Cross-Language Bridge ──────────────────────────
cpm bridge inspect python       # Inspect available RPC methods on host
cpm bridge inspect node
cpm bridge call python:math.sqrt '[9]'
cpm bridge call node:crypto.sha256 '["hi"]'
cpm bridge status

# ── Shortcuts ──────────────────────────────────────
cpm i    → cpm init         cpm a  → cpm add
cpm d    → cpm detect       cpm rm → cpm remove
cpm is   → cpm install      cpm up → cpm update

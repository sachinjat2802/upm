📖 Migration Guide

Move Any Existing App to UPM

Zero breaking changes. Migrate Next.js, React, FastAPI, NestJS, Express, Rails, or Django apps to UPM in 5 simple steps.

1

Scan Existing Repository Ecosystems

Open your existing project directory in terminal and run upm detect. UPM automatically scans your project markers, lockfiles, and manifests without modifying any files.

# Navigate to your existing codebase cd /path/to/my-existing-app # Scan multi-signal detection scores upm detect
2

Initialize UPM Manifest (Zero Code Changes)

Run non-interactive initialization. UPM creates a clean upm.toml manifest file. All your existing package.json, pyproject.toml, or Cargo.toml files remain 100% intact.

# Initialize UPM in existing folder without overwriting existing code upm init -y
✔ Zero Breaking Changes: Existing build scripts, npm run dev, and python main.py files continue working exactly as before.
3

Add Foreign Ecosystem Packages (As Needed)

Want to introduce Python AI libraries into your Next.js app or Rust compute into your FastAPI app? Use smart auto-detecting package addition.

# Add Python library to your Next.js / Express app upm add pip:docling # Add Rust library upm add cargo:serde # Add Node.js library upm add npm:express
4

Drop In UPM Client SDK

Import the UPM SDK for Python (cpm_sdk.py) or Node.js/TypeScript (cpm_sdk.js) to invoke foreign language functions in 1 line of code.

// TypeScript / Node.js (Next.js, NestJS, Express) const { CpmBridge } = require('./sdk/node/cpm_sdk'); const bridge = new CpmBridge(); const result = await bridge.call('python:docling.parse', ['proposal.pdf']);
5

Verify Build & Security Lockfiles

Run concurrent ecosystem installation and security lockfile auditing.

# Install all detected ecosystems concurrently in parallel upm install --parallel # Audit lockfiles and security vulnerabilities upm audit

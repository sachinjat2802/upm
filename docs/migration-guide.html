📖 Migration Guide

Move Any Existing App to CPM

Zero breaking changes. Migrate Next.js, React, FastAPI, NestJS, Express, Rails, or Django apps to CPM in 5 simple steps.

1

Scan Existing Repository Ecosystems

Open your existing project directory in terminal and run cpm detect. CPM automatically scans your project markers, lockfiles, and manifests without changing any files.

# Navigate to your existing codebase cd /path/to/my-existing-app # Scan multi-signal detection scores cpm detect
2

Initialize CPM Manifest (Zero Code Changes)

Run non-interactive initialization. CPM creates a clean upm.toml manifest file. All your existing package.json, pyproject.toml, or Cargo.toml files remain 100% intact.

# Initialize CPM in existing folder without overwriting existing code cpm init -y
✔ Zero Breaking Changes: Existing build scripts, npm run dev, and python main.py files continue working exactly as before.
3

Add Foreign Ecosystem Packages (As Needed)

Want to introduce Python AI libraries into your Next.js app or Rust compute into your FastAPI app? Use smart auto-detecting package addition.

# Add Python library to your Next.js / Express app cpm add pip:docling # Add Rust library cpm add cargo:serde # Add Node.js library cpm add npm:express
4

Drop In CPM Client SDK

Import the CPM SDK for Python (cpm_sdk.py) or Node.js/TypeScript (cpm_sdk.js) to invoke foreign language functions in 1 line of code.

// TypeScript / Node.js (Next.js, NestJS, Express) const { CpmBridge } = require('./sdk/node/cpm_sdk'); const bridge = new CpmBridge(); const result = await bridge.call('python:docling.parse', ['proposal.pdf']);
5

Verify Build & Security Lockfiles

Run concurrent ecosystem installation and security lockfile auditing.

# Install all detected ecosystems concurrently in parallel cpm install --parallel # Audit lockfiles and security vulnerabilities cpm audit

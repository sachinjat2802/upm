1-Line Cross-Language RPC Bridge

Import SDKs in Python, Node, Go, or Rust and execute foreign methods directly.

// Node.js / TypeScript calling Python AI library const { CpmBridge } = require('./sdk/node/cpm_sdk'); const bridge = new CpmBridge(); // Call python:math.sqrt over stdio RPC const result = await bridge.call('python:math.sqrt', [144]); console.log(result); // → 12.0

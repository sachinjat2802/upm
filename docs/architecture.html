Scoring Engine

Each registered adapter is evaluated against the filesystem using five weighted signals:

SignalWeightDescriptionExample
Lockfile Present+100Ecosystem-specific lockfile existspnpm-lock.yaml, uv.lock
Manifest Marker+80Marker string inside manifest file[tool.poetry] in pyproject.toml
Manifest Present+40Standard manifest file existspackage.json, Cargo.toml
Glob Match+30File extension or pattern match*.csproj, *.gemspec
Directory Indicator+20Output/dependency folder presentnode_modules/, .venv/
Declared Priority+0-4Adapter-defined tie-breakerpnpm (4) vs npm (1)

Winner Determination Rules

  • Language Grouping — Ecosystems are grouped by language (e.g. npm, pnpm, yarn, bun are all "javascript").
  • Highest Score Wins — The adapter with the highest total score within each language group becomes the winner.
  • Polyglot Retention — Winners from distinct language groups all coexist. A project can have pnpm (JS) + uv (Python) + cargo (Rust) simultaneously.

🌉 L2' Invocation Engine (upm-bridge/1)

Bridges runtime boundary calls between host environments over stdio streams using a framed JSON protocol.

Communication Model

🦀 Host Process (Rust)
BridgePeer + HandleRegistry
──── stdin ────▶
upm-bridge/1
◀──── stdout ────
🐍 Language Host
python_host.py / node_host.js

Key Components

📡

Transport Layer

4-byte Big-Endian length-prefixed framing over stdin/stdout. Max message size: 64 MB. Trait-based for extensibility.

📦

Value Codec

Universal UpmValue enum extending JSON with $blob (binary), $ref (handles), and $fn (callbacks).

🗂️

Handle Registry

Thread-safe registry for object references and callback closures. Supports batched release via ReleaseHandles messages.

🔄

Bridge Peer

Bidirectional RPC peer that sends requests, dispatches $fn: callbacks, processes handle releases, and handles ping/pong.

🚀

Host Supervisor

Generic spawn_host(program, script) that launches any language runtime with kill_on_drop cleanup.

⚡

Transport Tiers

FFI (~0.88µs) · Embed (~2.6µs) · RPC (~156µs, default). Escalates automatically by capability.

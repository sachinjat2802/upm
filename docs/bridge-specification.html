1. Transport Framing

All messages sent over standard input/output (stdio) MUST be framed with a 4-byte Big-Endian uint32 length header preceding the UTF-8 encoded JSON body payload.

┌───────────────────────┬───────────────────────────────────────┐
│  Length (4-byte BE)   │  JSON Envelope Payload (UTF-8 Bytes)  │
├───────────────────────┼───────────────────────────────────────┤
│  0x00 0x00 0x00 0x3E  │  {"type":"request","id":"1", ...}     │
└───────────────────────┴───────────────────────────────────────┘
Safety Guard: Standard implementations enforce a maximum message payload size of 64 MB (MAX_MESSAGE_SIZE) to prevent OOM errors from malformed headers.

2. Wire Envelope Message Types

Messages exchanged between host and peer runtimes use a tagged discriminator type field.

RPC Invocation Request

{
  "type": "request",
  "id": "req_1001",
  "method": "python:math.sqrt",
  "args": [144.0],
  "kwargs": {}
}JSON

RPC Invocation Response (Success)

{
  "type": "response",
  "id": "req_1001",
  "result": 12.0,
  "error": null
}JSON

RPC Invocation Response (Error)

{
  "type": "response",
  "id": "req_1001",
  "result": null,
  "error": {
    "error_type": "ValueError",
    "message": "math domain error",
    "stack_trace": "Traceback (most recent call last):\n..."
  }
}JSON

Batched Handle Release (Garbage Collection)

{
  "type": "release_handles",
  "handles": ["ref_1001", "fn_2002"]
}JSON

Ping & Pong Keepalive

{ "type": "ping", "id": "p1" }

3. Value Representation Semantics

The universal value type UpmValue seamlessly extends JSON with binary blobs, object handle references, and invokable callbacks.

TypeJSON Sentinel RepresentationSemantics & Behavior
Primitives 123, "text", true, [...], {...} Copied directly by value over JSON.
Out-of-band Blob {"$blob": "uuid", "data_base64": "...", "len": 1024} Base64-encoded binary payload transferred efficiently without string mangling.
Object Handle {"$ref": "ref_uuid", "type_name": "Counter"} Opaque handle retained in host memory. Passing it back references the same object.
Function Callback {"$fn": "fn_uuid"} Remote invokable callback handle. Can be called back as $fn:fn_uuid.
Handle Lifecycle & GC: When object or callback references are no longer needed by a foreign runtime, a batched release_handles message is emitted to reclaim memory in the peer's HandleRegistry.
